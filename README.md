## 📋 Sobre o Projeto

Landing page + cardápio digital criado como exemplo de entrega para restaurantes e negócios do setor alimentício. O projeto demonstra como um restaurante pode atrair mais clientes, apresentar seu cardápio de forma digital e facilitar pedidos via WhatsApp.

---

## ✨ Funcionalidades

- Landing page com identidade visual apetitosa e moderna
- Cardápio digital organizado por categorias
- Integração com WhatsApp para pedidos e reservas
- Seção de destaques e pratos especiais
- Galeria visual dos pratos
- Informações de localização, horário de funcionamento e contato
- Design 100% responsivo (mobile, tablet e desktop)
- Otimizado para SEO local
